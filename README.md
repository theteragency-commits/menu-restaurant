# Menu restaurant

Page statique (HTML/CSS/JS, sans backend) hébergée sur GitHub Pages.

## Modifier le menu

Tout le contenu est dans **`menu.js`** : nom, slogan, adresse, téléphone,
WhatsApp, catégories, plats et prix. Modifier, commit, push : GitHub Pages
republie en 1 à 2 minutes.

## Tester en local

Double-cliquer sur `index.html` (pas besoin de serveur).

## Fichiers

- `index.html` — structure de la page
- `style.css` — apparence (clair/sombre automatique)
- `app.js` — affichage, onglets, recherche
- `menu.js` — le contenu
